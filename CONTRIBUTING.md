# Contributing

Thank you for helping improve this project showcase. Useful contributions include clearer documentation, corrected public links, accessible descriptions and reproducible public-page feedback.

## Choose the right place

- Use [Report an issue](https://github.com/obash11/setmore-creatives-hub/issues/new?template=bug_report.yml) for broken links, layout problems or documentation errors.
- Use [Suggest an improvement](https://github.com/obash11/setmore-creatives-hub/issues/new?template=improvement.yml) for practical ideas.
- Use the [live website](https://setmore.page.gd) for programme applications, orders, quotations or private account support. GitHub issues are public.

## Before opening a pull request

1. Keep the change focused and explain the user benefit.
2. Preserve factual project descriptions; do not invent metrics, awards, testimonials or backend capabilities.
3. Confirm local document and image references and run the checker below.
4. Explain what you changed and how you checked it. Only submit content you have the right to share.

```sh
node .github/scripts/check-showcase.cjs
```

Node.js 18 or newer is required. No package installation is needed. The issue-form files use JSON syntax, which is also valid YAML.

## Protect people and production systems

Do not submit production application files, database exports, credentials, private contact details, student/customer records or unredacted private screenshots. Do not create false registrations, orders or support requests while reviewing the live sites.

For security-sensitive concerns, follow [SECURITY.md](SECURITY.md) instead of posting details in a public issue. This repository is a showcase, not an open-source distribution of the live application. Public visibility does not grant reuse rights to business branding, photographs or artwork.
