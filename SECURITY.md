# Privacy and security reporting

## Scope

This repository contains project documentation, presentation assets and a local documentation-checking utility. It does not distribute the production application, its database or private user records. The checker is a limited documentation guardrail, not a security certification or comprehensive secret scanner.

## Public reports

Ordinary broken links, layout issues and documentation corrections can use the repository's issue forms. Remove private details and crop or redact screenshots before posting. Never publish passwords, tokens, student/customer records, private email addresses or account identifiers.

## Sensitive concerns

Do not post vulnerability details or exposed data in public issues. For a concern involving the live website, use its official contact options at [https://setmore.page.gd](https://setmore.page.gd) to request a private reporting channel before sharing sensitive details.

For the other featured project, follow the contact links on its live website: [JIAAD Foundation](https://jiaadfoundation.co.ke) or [Setmore Creatives Hub](https://setmore.page.gd).

Do not access, download or modify other people's data to demonstrate a problem. No private security inbox, guaranteed response time or bug-bounty programme is advertised by this showcase.
